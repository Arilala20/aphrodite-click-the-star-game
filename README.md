# aphrodite-click-the-star-game
HAMK Assignment 14 – Simple HTML5 JavaScript Game

Click the Star! — Simple Game
A quick browser game for HAMK Assignment 14 by Group Aphrodite.
How to play
1. Open click-the-star.html in Chrome or Edge.
2. Click Start Game.
3. Click the star as many times as possible before the 20-second timer reaches zero.
4. The best score is saved in the browser.
Technologies
HTML5, CSS3 and JavaScript. No installation or internet connection required.
